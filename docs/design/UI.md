# User Interface Design for Ham2K PoLo Next

### The "Current Operation"

The app is built around the concept of a "Current Operation" that the user is actively involved in. 

Some screens or windows might be on a "global context", with no specific operation context, 
like the Settings Screen, or the main list of operations.

On a mobile device you might only be involved in a single operation at a time, but on a desktop environment, you might have
multiple windows open, each with a specific operation context.

The main view for an operation is the list of QSOs, always sorted by date, with the most recent one at the bottom. And at the bottom of this list you'll find the logging controls, either to add a new QSO or to edit currently selected one.
