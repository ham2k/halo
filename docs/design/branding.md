The app is formally called "Ham2K Logger".

We use com.ham2k.logger as the package name or identifier.

We use "HaLo" or "halo" internally on package names, identifiers, etc, but never on content shown to users.

On desktop versions it identifies itself as "Ham2K Logger" while on mobile versions it uses "Ham2K Portable Logger".

In places where we show the app name alone, like in headers or dialog titles, we use a graphic for the Ham2K wordmark, and then the text "Logger" or "Portable Logger" either to the right of the logo, left aligned and vertically centered, or below the logo centered horizontally.

When mentioning the app name in text, we use the formal name "Ham2K Logger" or "Ham2K Portable Logger". We never refer to it as "HaLo".
